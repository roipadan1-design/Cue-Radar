# Fellow. — Agent roster

Team of specialized agents the owner and the main Claude Code session dispatch work to. Definitions live in `.claude/agents/`.

| Agent | Handles | Doesn't handle |
|---|---|---|
| `researcher` | Finding/verifying real opportunities & sources, competitive/market research, vision docs | Writing app code, deciding strategy |
| `ux-ui-designer` | Screen/flow design, design references, accessibility, copy-tone review, aesthetic spec docs | App logic, naming/headline copy |
| `frontend-engineer` | Next.js/React/Tailwind implementation, one task at a time | Schema/migrations, deciding what to build |
| `backend-data-engineer` | Supabase schema, migrations, RLS, the sync script | UI code, sourcing content |
| `qa-release` | Verifying a task/PR actually works, mobile walkthroughs, pass/fail punch lists | Implementing fixes |
| `task-planner` | Turning the owner's plain-language asks into precise task files | Writing app code, strategy calls |
| `business-dev-manager` | Business plan, monetization/partnership strategy, growth sequencing | Code, design, naming |
| `creative-director` | Naming, headline/tagline copy, brand voice | Screen layout, visual tokens |

Updated as the project needs more specialized roles — this list isn't fixed.
